## 功能概述

本系统根据油井地面示功图数据，求解抽油杆波动方程，计算井下泵功图，用于油井工况诊断。

### 核心功能

1. **数据导入** — 支持加载 `.txt` 格式的油井示功图数据，内置 DK3、DK6、S22 三口井
2. **傅里叶级数重构地面示功图** — 对地面位移和载荷数据做 FFT 拟合，重构后与原始数据对比，验证拟合精度
3. **波动方程求解泵功图** — 从地面示功图计算井下泵功图，支持两种方法：
   - **傅里叶级数法（Gibbs 方法，推荐）** — 将边界条件展开为傅里叶级数，通过复波数传递函数求解
   - **有限差分法（实验性）** — 直接离散波动方程，多周期迭代至稳态
4. **数据导出** — 计算结果可导出为 CSV 或 JSON 格式

## 计算方法原理

### 傅里叶级数重构

对周期信号 f(θ) 做傅里叶级数展开：

```
f(θ) = a₀/2 + Σ[aₙ·cos(nθ) + bₙ·sin(nθ)]    n = 1, 2, ..., N
```

系数通过 FFT 计算，用前 N 阶谐波重构信号并与原始数据对比。

### 波动方程（Gibbs 方法）

抽油杆纵向振动方程：

```
∂²u/∂t² = a²·∂²u/∂x² - c·∂u/∂t
```

其中 a = √(E/ρ) 为波速，c 为阻尼系数。

**已知**地面边界条件（x = 0）：
- 位移 u(0, t) = D(t)
- 载荷 F(0, t) = EA·∂u/∂x|ₓ₌₀

**求解**泵端（x = L）的位移和载荷，得到泵功图。

将 D(t) 和 F(t) 展开为傅里叶级数，通过复波数传递函数：

```
kₙ = αₙ + i·βₙ
αₙ = (nω / a√2)·√(√(1+(c/nω)²) - 1)
βₙ = (nω / a√2)·√(√(1+(c/nω)²) + 1)
```

将傅里叶系数从地面传播到泵深度 L，重构泵功图。
